# リリース前検証手順書（Pre-release Review）

本ドキュメントは、Usugami のソースコード、配布成果物（パッケージ）、および手動操作の品質を検証するための手順書です。自動テストの結果と実環境での手動確認結果は、それぞれ分けて記録します。

---

## 1. 自動チェック

Windows PowerShell およびサポート対象の Node.js LTS（v22 以上）環境で実行します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Package
Get-Content .\dist\self-test.txt
Get-FileHash .\dist\Usugami-windows.zip -Algorithm SHA256
Get-Content .\dist\Usugami-windows.zip.sha256
```

### 自動テストの確認項目
- **ビルドとテストの完了**：アプリ本体のビルド、セルフテスト、および拡張機能のテストスイートがすべてエラーなく成功すること。
- **アプリのセルフテスト**：
  - 文書データ（`.usugami`）の往復保存（保存 → 読み込み）でデータが正しく再現されること。
  - 保存・読み込み失敗時にも既存の作業状態が安全に保持されること。
  - DTD（外部実体参照）、深すぎる XML 階層、未知の要素、不正な値、サイズ・累計上限を超過したデータが確実に拒否されること。
- **PC 内通信（HTTP 受信）のテスト**：
  - 正しい接続キーを持つ正当なリクエストのみが受理されること。
  - 外部 Web Origin、不正な Host ヘッダー、無効なキー、重複ヘッダー、`Transfer-Encoding`、必須 JSON フィールドの欠落、過大なペイロードがすべて確実に遮断されること。
  - 少量ずつデータを送り続ける接続（低速攻撃）がタイムアウト期限（1,500 ms）で切断されること。
- **ブラウザー拡張機能のテスト**：
  - 入力値および送信元フレームの検証、アクティブタブの判別、接続キーの保護（コンテンツスクリプトへの非公開）が機能していること。
  - リダイレクトの拒否、接続失敗時やタブ切り替え時における基準座標の再計算が正しく動作すること。
- **配布パッケージの検証**：
  - 生成された `Usugami-windows.zip` のハッシュ値と、同梱される `.sha256` ファイルの内容が完全一致すること。
  - zip パッケージ内に許可リストに登録したファイル（`Usugami.exe`、`README.md`、`SECURITY.md`、`LICENSE`、拡張機能の関連ファイル、`docs/toolbar.png`）のみが含まれ、ローカル設定・復元データ・接続キー・テストログ等が混入していないこと。

## 2. 手動チェック

- **基本操作**：
  - アプリの起動および終了がスムーズに行えること。
  - ショートカットキー（`Ctrl + Alt + A`）またはボタンによる「描画モード」と「操作モード」の切り替えが正しく機能すること。
  - 一時非表示（`Ctrl + Alt + H`）、元に戻す（Undo） / やり直す（Redo）が正常に動作すること。
  - ディスプレイ構成の変更やマルチモニターの切断後でも、ツールバーが画面内の安全な位置に復帰すること。
- **描画とファイル操作**：
  - ペン（フリーハンド）、図形、テキスト、貼り付け画像を含む文書が正しく保存され、再読み込みで完全に復元されること。
  - 透明背景 PNG での書き出し、およびクリップボードへのコピーが正常に行えること。
  - 破損した文書や不正なファイルを開こうとした際にもエラーハンドリングが行われ、既存の描画内容が保護されること。
- **ブラウザー拡張機能の導入と接続**：
  - Chromium 102 以降の Chrome / Edge に `extension/` フォルダーを読み込めること。
  - 接続キーの設定後、ツールバーアイコンのバッジが「ON」となり正常接続が確立されること。
- **ページ追従機能の検証**：
  - ローカルループバック限定の HTTP サーバー経由で `tests/scroll-test.html` を開き、ページの縦横スクロールに書き込みが連動すること。
  - タブの切り替え、ウィンドウのアクティブ切り替え、アプリ再起動後の再接続、接続キー更新時の挙動が想定通りであること。
- **配布パッケージの展開確認**：
  - 生成された配布用 zip を別の空フォルダーに解凍し、単体で正常に起動できること。
  - 同梱されたドキュメントや説明画像が正常に参照できること。

## 3. 公開リポジトリの準備

- **機密情報の排除**：ソースコードやコミット履歴に、個人の作業ファイル、プライベートな接続キー、認証情報、不要なビルド成果物が含まれていないことを確認します（※ `.gitignore` は既にコミット済みのファイルや過去の履歴を削除しないため注意）。
- **GitHub の設定**：
  - GitHub Actions CI が正常に通過していることを確認します。
  - リポジトリの **Security** 設定にて [Private vulnerability reporting](https://docs.github.com/ja/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) を有効化します。
- **検証結果の記録**：実施日、検証に使用した OS・ブラウザー・ランタイムの各バージョン、自動テストおよび手動確認の結果（および未実施項目）を記録します。

### 2026-11-04 検証記録（操作性の修正と文書修正後の再パッケージ）

README.md と SECURITY.md の文言修正に加え、次の点を修正し、配布用 zip を作り直して自動チェックを再実施しました。

アプリ本体（`src/Usugami.cs`）:
- 起動時の「復元しますか？」ダイアログを開いたまま 60 秒以上たつと、自動バックアップ処理が復元ファイルを削除してしまう不具合を修正。
- `.usugami` ファイルから起動すると復元の確認が出ず、60 秒後に前回の復元ファイルが削除される不具合を修正（ファイルを開く前に確認するように変更）。
- 文書の上限（画像の合計 1 億画素・ファイル 64 MiB）を画像の追加時にも確認し、超える場合は縮小を提案するように変更（これまでは保存時に初めてエラーになり、保存も自動バックアップもできなくなった）。ファイルサイズの見積もりには、既存の画像に加えて線・テキストの量も含めています。画像の追加後に線を大量に描き足した場合は保存時の検査に任せ、その際は下記の警告で知らせます。
- 自動バックアップに失敗したとき、ツールバーと通知領域で一度警告するように変更（これまでは失敗が利用者に伝わらなかった）。
- 描画中に「使い方」ウィンドウが `Esc` で閉じない不具合を修正（`Esc` がグローバルホットキーとして先に処理されていたため）。
- 拡張機能の接続キーが一致しないとき、ツールバーに「接続キーが不一致」と表示するように変更（これまでは「拡張の接続待ち」のままで原因が分からなかった）。

ブラウザー拡張機能:
- 接続キーの保存領域を使用できないとき、「Usugami が見つかりません」ではなく専用の状態（バッジ `ERR`、設定画面「接続キーを読み書きできません」）を表示するように変更。
